# Калькулятор UMEDJON — обновления

Официальный канал обновлений Android-приложения «Калькулятор UMEDJON».

Пакет: `tj.umedjon.calculator`. Обновления устанавливаются поверх предыдущей версии с сохранением истории и настроек.

Приложение проверяет новые версии при входе. Скачивание начинается после нажатия «Скачать и установить». Перед установкой проверяются размер APK, SHA-256, пакет, версия и исходная подпись. Установку подтверждает пользователь в системном окне Android.

Подписанные APK и `update.json` публикуются в Releases. Маленький файл `updates/stable.json` описывает последний проверенный публичный выпуск. Черновики и предварительные версии не предлагаются как стабильные обновления.

В этом публичном репозитории не хранятся закрытый ключ подписи и пароли.
