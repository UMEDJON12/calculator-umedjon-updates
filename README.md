# Калькулятор UMEDJON — обновления

Официальный канал обновлений Android-приложения «Калькулятор UMEDJON».

[Скачать последнюю версию](https://github.com/UMEDJON12/calculator-umedjon-updates/releases/latest)

Пакет: `tj.umedjon.calculator`. Обновления устанавливаются поверх предыдущей версии с сохранением истории и настроек.

Начиная с 1.0.7 приложение проверяет новые версии при входе и раз в минуту, пока открыто. Скачивание начинается после нажатия «Скачать и установить». Перед установкой проверяются размер APK, SHA-256, пакет, версия и исходная подпись. Установку подтверждает пользователь в системном окне Android. В настройках доступны ручная проверка, установка скачанного APK и отключение автоматической проверки.

Версии 1.0.6 и ниже нужно один раз обновить вручную, установив новый APK поверх старого приложения.

В 1.0.7 добавлены голосовой ввод выражений и озвучивание предварительного результата до нажатия «Равно». Итог после «Равно» озвучивается повторно. Предварительное озвучивание можно отключить в настройках.

Подписанные APK и `update.json` публикуются в Releases. Маленький файл `updates/stable.json` описывает последний проверенный публичный выпуск. Черновики и предварительные версии не предлагаются как стабильные обновления. Перед публикацией workflow проверяет подпись и запускает тесты на Android 15.

В этом публичном репозитории не хранятся закрытый ключ подписи и пароли. Вычисления работают без интернета; распознавание речи выполняет установленная на телефоне служба.
